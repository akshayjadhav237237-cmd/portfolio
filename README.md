# Akshay Jadhav — Portfolio V3

Welcome to the official repository for my personal developer portfolio. This is a sleek, modern, and highly interactive single-page portfolio designed to showcase my projects, hackathon wins, technical skillset, and contact information.

Designed with premium glassmorphism aesthetics, custom micro-interactions, custom cursor tracking, and smooth animations.

---

## 🚀 Tech Stack & Libraries Used

- **Core Structure:** HTML5, CSS3, Vanilla JavaScript
- **Animations:** [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/) & [ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Smooth Scroll:** [Lenis Smooth Scroll](https://github.com/studio-freight/lenis)
- **Typography:** Clash Display, Cabinet Grotesk, Fira Code (via Google Fonts)

---

## ⚡ Key Features

- **Frosted Glass Navigation:** Translucent glassmorphism navbar that adapts and becomes more compact on scroll.
- **Dynamic Section Headings:** Interactive three-line heading style with custom hover-to-glow text transitions.
- **Custom Cursor:** Custom cursor dot and trailing ring that grows dynamically when hovering over clickable elements.
- **Interactive Project Showcase:** Responsive grid layouts representing key projects. Hovering over cards highlights the language/tech stack tags with custom orange glows.
- **Smooth Performance:** Lightweight animations powered by GSAP with high frame rates and hardware acceleration.
- **Responsive Layout:** Tailored design that automatically adapts to desktop, tablet, and mobile displays.

## 🔧 Local Development / How to Run

Since the website is built using vanilla HTML/CSS and lightweight CDN-loaded libraries, you can run it instantly without complex builds:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akshayjadhav237237-cmd/portfolio.git
   cd portfolio
   ```

2. **Run a local server:**
   - **Using Python (Recommended):**
     ```bash
     python -m http.server 3000
     ```
   - **Using Node.js / Live Server:**
     ```bash
     npx serve
     ```

3. Open **`http://localhost:3000/akshay-portfolio-v3.html`** in your browser.
